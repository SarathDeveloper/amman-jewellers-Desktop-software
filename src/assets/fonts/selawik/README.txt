Selawik
=======

Files in this directory are the Selawik typeface by Microsoft, used as the
metric-compatible stand-in for Segoe UI on macOS (where Segoe UI is absent).

- selawik-regular.woff2   (weight 400)
- selawik-semibold.woff2  (weight 600)
- selawik-bold.woff2      (weight 700)

Source: https://github.com/microsoft/Selawik (release 1.01)
